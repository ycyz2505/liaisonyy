# liaisonyy 总管理员使用指南

> 适用版本：0.1.0（首个可用版本）
> 总管理员只有一个，由服务端初始化时创建。

---

## 1. 部署服务端

### 1.1 放置文件

1. 在 **D 盘**建一个目录，例如 `D:\liaisonyy\`。
2. 把 `liaisonyy-server.exe` 放进去。
3. 双击运行。第一次启动会在同目录创建：
   - `data\liaisonyy.db`：数据库（密文 + 元数据）
   - `data\keyring.bin`：服务器主密钥（审计链、公开媒体加密）
   - `data\tls\`：自签 TLS 证书
   - `data\setup_token.txt`：初始化口令
   - `logs\`：日志
4. 控制台会打印：
   - `SETUP TOKEN: 12345678`（初始化口令）
   - `API: https://127.0.0.1:47820/...`
   - `Admin: https://127.0.0.1:47820/admin`

> **不要把服务端放在 C 盘**：教室电脑 C 盘可能还原，数据库和密钥会丢。所有数据都在 `data\` 里，备份时整个目录一起拷。

### 1.2 防火墙

首次运行 Windows 会弹防火墙提示，请允许：

- TCP 47820（客户端 API / 管理后台）
- UDP 47821（服务发现，后续版本使用）

如果没弹窗或误点了拒绝，用管理员权限执行：

```bash
netsh advfirewall firewall add rule name="liaisonyy" dir=in action=allow protocol=TCP localport=47820
```

### 1.3 开机自启（现实限制）

C 盘还原会清掉启动项。程序每次启动会尝试重建自启项，但**开机后仍需要有人第一次双击**。建议每天早上由值日生/管理员启动一次；如果学校有还原卡白名单或域控，可交给它。

---

## 2. 初始化服务端（只做一次）

1. 在服务端那台电脑（或同一内网的电脑）运行 `liaisonyy.exe` 客户端；`liaisonyy.exe` 和 `WebView2Loader.dll` 要放在同一目录，系统需要 WebView2。
2. 欢迎页确认服务器地址是 `https://127.0.0.1:47820`（或服务器 IP），点「连接服务端」。
3. 看到「服务端尚未初始化」→ 点「初始化服务端」。
4. 填写：
   - **初始化口令**：控制台打印的 8 位数字
   - **总管理员 YY 号**：例如 `admin`（3–20 位字母数字下划线，不能纯数字）
   - **显示名称**：例如「总管理员」
   - **密码**：8 位以上，含字母和数字，建议 12 位以上
5. 点「初始化」。
6. 屏幕会显示一个 **恢复码**（16 位数字），只显示一次：
   - **立刻抄下来，离线保存**（不要存在服务器上）。
   - 忘记总管理员密码时，它是最后的恢复手段；丢失后所有管理员加密数据可能无法恢复。
7. 初始化完成后，用总管理员 YY 号 + 密码登录。

> 总管理员账号不绑定班级，不显示在班级账号列表里；用「uid/YY号登录」入口登录。

---

## 3. 创建班级与导入名单

在客户端登录总管理员 →「我」→「管理」：

### 3.1 创建班级

1. 填「名称」（例如 `高二(5)班`）和「年级」。
2. 点「创建」。
3. 客户端会自动生成该班的**班级托管密钥**并上传；服务端不保存明文密钥。
4. 创建成功后，该班自动拥有一个班级群。

### 3.2 导入名单

1. 在「导入名单」里选择班级。
2. 在文本框里每行写一个学生姓名（例如从 Excel 复制一列）。
3. 点「导入」。
4. 学生注册时就能在名单里选自己的名字。

> 名单的导入/编辑**只有总管理员**能做；班级管理员只能查看。重名学生建议在姓名后加学号后四位区分。

### 3.3 指定班级管理员

1. 先让学生注册账号（或你手动确认其 UID）。
2. 在「设班级管理员」里填班级 ID 和学生 UID，点「设置」。
3. 该学生角色变为班级管理员，并拿到本班托管密钥的包裹。
4. 班级管理员必须用密码登录。

---

## 4. 网页管理后台

浏览器打开 `https://服务器IP:47820/admin`（自签证书会提示不安全，选择继续访问）。

- 用总管理员 YY 号 + 密码登录。
- **概览**：账号数、在线、今日消息、消息总数、班级数、待处理申请、数据库大小。
- **班级与名单**：查看班级、导入名单（每行一个姓名）。
- **审计日志**：最近 200 条管理操作。
- 网页后台**不做解密、不展示任何聊天记录**；班级创建需要客户端生成托管密钥，所以请在客户端创建班级。

---

## 5. 重置密钥

总管理员可以为**任意班级**的学生生成重置密钥：

1. 客户端「管理」页 →「生成重置密钥」。
2. 填学生 UID、有效期（分钟），点「生成」。
3. 把 8 位密钥线下告诉学生。
4. 学生用「忘记密码」完成重置。

班级管理员也可以为本班学生生成；总管理员是兜底。

---

## 6. 数据备份与恢复（0.1.0 手动）

当前版本**没有自动备份**，请手动：

1. 停掉服务端（关闭控制台窗口，或任务管理器结束 `liaisonyy-server.exe`）。
2. 把整个 `D:\liaisonyy\data\` 目录复制到 U 盘/另一块盘。
3. 恢复时停服 → 用备份替换 `data\` → 重新启动。

> `keyring.bin` 必须一起备份；只备份数据库会导致审计链和公开媒体无法解密。用户消息密钥在数据库的包裹里，用户密码不变即可继续解密。
>
> 备份频率建议：每周一次 + 大版本升级前一次。

---

## 7. 升级与迁移

### 7.1 升级

0.1.0 还没有自动更新。升级步骤：

1. 停服。
2. 备份 `data\`。
3. 用新 `liaisonyy-server.exe` 替换旧 exe（不要动 `data\`）。
4. 启动，检查日志和网页后台。

客户端同理：替换 `liaisonyy.exe`，保留 `data\`（本机缓存/设置）。

### 7.2 迁到 Linux 云服务器（后续）

源码支持 Linux 构建；当前版本尚未提供一键迁移脚本。步骤大致：

1. 在 Linux 上编译/放置 `liaisonyy-server`。
2. 把 `data\` 整个目录拷过去。
3. 配置端口/证书（自签证书可继续用）。
4. 客户端设置里把服务器地址改成云服务器地址。
5. 注意：云服务器需要放行 TCP 47820；管理后台默认只监听本机，公网访问需额外配置。

## 8. 安全建议

- **恢复码**离线保存（纸质/加密 U 盘），不要放在服务器电脑上。
- 总管理员密码使用强密码（12 位以上），不要与学生共用。
- 不要把 `data\keyring.bin` 发给任何人。
- 管理后台默认只监听 `127.0.0.1`；需要局域网访问时再开，并注意自签证书信任问题。
- 定期检查审计日志中的异常登录/管理操作。
- 教室电脑可能被同学接触；离开时锁屏，服务端进程不要随意交给学生操作。

---

## 9. 当前版本限制（0.1.0）

以下功能在设计稿中，但当前版本还没有完成，请不要向学生承诺：

- 自动更新（客户端/服务端）
- 内网 UDP 自动发现（当前需手动填服务器地址）
- 转班申请与审批
- 举报/禁言/消息不展示
- 管理员聊天解密查看工具（当前只能生成重置密钥）
- 头像/主页背景上传
- 内置完整 26 键/9 键键盘（当前只有 PIN 数字键盘，其他用物理键盘）
- 老板键（当前只有红色关闭按钮）
- 自动备份、CSV 导出、班级公告置顶
- WebSocket 实时推送（当前客户端每 2 秒轮询）

这些会在后续版本补齐；当前版本已能完成注册、登录、加好友、私聊、班级群、重置密码等核心流程。

## 10. 常见问题

**Q：服务端启动后客户端连不上？**
A：确认服务端进程在运行；确认防火墙放行 TCP 47820；确认客户端地址是 `https://服务器IP:47820`；自签证书提示可以忽略（客户端已允许）。

**Q：初始化口令丢了？**
A：在 `data\setup_token.txt` 里；如果服务端已经初始化，该口令不再需要。

**Q：总管理员密码忘了？**
A：用初始化时抄下的恢复码恢复（当前客户端还没有恢复码界面，需后续版本或手动处理）；如果恢复码也丢了，管理员加密数据可能无法恢复。

**Q：数据库越来越大？**
A：服务端永久保存聊天记录（按需求不删）。文本消息很小；定期备份并关注磁盘剩余空间。

**Q：可以一个学校多个服务端吗？**
A：当前按「全校一个服务端」设计；多个服务端会导致客户端发现冲突（后续版本），请只保留一个。
