# liaisonyy 班级管理员使用指南

> 适用版本：0.1.0（首个可用版本）
> 班级管理员由总管理员指定；每个班一个。

---

## 1. 成为班级管理员

- 总管理员在客户端「管理」页把某个本班学生设为班级管理员。
- 被指定后，该账号角色变为「班级管理员」。
- 班级管理员**必须用密码登录**（不能用 PIN），因为管理员操作需要更高的安全级别。
- 如果总管理员还没有给你分配，你的「管理」页可能无法生成重置密钥；请联系总管理员。

---

## 2. 登录与入口

1. 双击 `liaisonyy.exe`，托盘左键打开小窗。
2. 点自己的账号，用**密码**登录。
3. 底部进入「我」→「管理」，打开管理页。
4. 也可以在浏览器打开 `https://服务器IP:47820/admin`，用班级管理员账号登录网页后台；网页后台主要给总管理员用，班级管理员在客户端管理页操作更方便。

---

## 3. 管理页功能

### 3.1 查看本班统计

点「刷新统计」，可以看到：

- 本班账号数
- 在线人数
- 今日消息数
- 消息总数
- 待处理好友申请
- 数据库大小

统计是**本班范围**；看不到别班数据。

### 3.2 生成重置密钥（最常用）

学生忘记密码时：

1. 在「生成重置密钥」区域填：
   - **学生 UID**（学生可以在「我」页看到自己的 UID；也可以从账号列表看到）
   - **有效期（分钟）**：例如 10、60、1440（24 小时）、10080（7 天）
2. 点「生成」。
3. 屏幕会显示一个 **8 位纯数字密钥**，只显示这一次，请立刻抄下来。
4. **线下**告诉该学生密钥和有效期。
5. 学生在登录页「忘记密码」里输入 UID/YY 号 + 密钥 + 新密码（可选新 PIN），即可重置。
6. 密钥只能用一次；输错 5 次或过期作废。需要时重新生成。

> 0.1.0 的班级管理员可以为本班学生生成重置密钥；重置时加密数据的恢复由客户端自动完成。如果学生连 PIN 也忘了，仍可重置登录密码，但旧聊天记录可能需要总管理员协助恢复。

### 3.3 班级群

- 每个班自动有一个班级群，全班账号都在里面。
- 班级管理员可以正常发言；班级公告当前版本以普通消息形式发送（置顶公告功能后续开放）。
- 新同学加入后看不到入群前的消息，这是加密设计决定的；如需让新同学了解旧通知，请重新发一遍。

### 3.4 名单

- 本班名单的**导入/编辑只有总管理员能做**；班级管理员只能查看（学生注册页会显示未注册名单）。
- 如果发现名单有误（错别字、重名、转班），请联系总管理员修改。

### 3.5 好友申请与班级群

- 班级管理员也是普通用户，可以加好友、私聊、在班级群发言。
- 学生之间的私聊内容，当前版本**不提供日常浏览入口**；请尊重同学隐私。

## 4. 当前版本暂未开放的功能

以下功能在设计稿中，但 0.1.0 还没有界面/接口，请先不要向学生承诺：

- 转班申请的审批（转入/转出）
- 举报处理、禁言、消息「不展示」
- 查看/导出本班聊天记录（管理员解密工具）
- 班级公告置顶
- 批量导出名单/统计 CSV

这些会在后续版本补上；当前遇到相关需求，请联系总管理员。

## 5. 日常处理建议

### 学生忘记密码

1. 确认学生身份（当面/线下）。
2. 生成 8 位密钥，告诉学生。
3. 提醒学生：密钥只一次、有效期有限；重置后旧 PIN 可能被清除（如果学生没填新 PIN，账号会变成仅密码登录）。
4. 如果学生重置后看不到旧聊天，联系总管理员做密钥恢复。

### 学生 PIN 输错被锁

- 等锁定时间过去再试；或让学生用密码登录。
- 如果学生忘记 PIN 但记得密码：用密码登录后，在设置里改 PIN（当前版本改 PIN 入口在「设置」/账号安全，后续版本会完善）。
- 如果密码也忘了：走重置密钥流程。

### 学生说「加不了好友」

- 确认对方 UID/YY 号正确。
- 确认双方不是已经好友、没有待处理申请。
- 好友申请每天有次数限制，等第二天再试。

### 学生说「班级群看不到消息」

- 新成员看不到入群前消息，这是正常的。
- 如果显示「等待群密钥同步」，让该学生重新登录；仍不行则联系总管理员。

---

## 6. 安全与隐私

- 班级管理员账号请使用强密码；不要和学生共用。
- 重置密钥相当于临时登录凭证，只能线下交给本人，不要发在群里。
- 不要尝试查看学生私聊；当前版本也没有这个入口。
- 管理操作会写入审计日志（总管理员可查）。
- 服务器是教室电脑，可能关机/还原；重要通知请同时用线下方式传达。
