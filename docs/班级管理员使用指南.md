# liaisonyy 班级管理员使用指南

> 适用版本：0.3.2
> 班级管理员由总管理员指定；每个班一个。

---

## 1. 成为班级管理员

- 总管理员在客户端「管理」页把某个本班学生设为班级管理员。
- 被指定后，该账号角色变为「班级管理员」。
- 班级管理员**必须用密码登录**（不能用 PIN），因为管理员操作需要更高的安全级别。
- 如果总管理员还没有给你分配，你的「管理」页可能无法生成重置密钥；请联系总管理员。

### 1.1 部署与启动客户端（班管职责）

客户端由班管统一部署，**不要让每个学生自己拷贝 exe**：

1. 从总管理员/交付包获取 `liaisonyy.exe` 和 `WebView2Loader.dll`。
2. 在教室电脑的 **D 盘**建目录（如 `D:\liaisonyy-client\`），把两个文件放进去；不要放 C 盘（还原会丢）。
3. 双击 `liaisonyy.exe` 启动；窗口不会自动弹出，点托盘图标打开小窗，确认能自动发现/连接服务端；在「设置」里确认服务器地址正确。
4. 给学生创建一个桌面快捷方式（指向 `D:\liaisonyy-client\liaisonyy.exe` 或实际路径），告诉他们双击这个快捷方式即可。
5. 系统需要 WebView2（学校电脑一般有 Edge/WebView2）；缺失时找总管理员。
6. 文本输入使用系统输入法（微软拼音/搜狗等）；PIN/密码页面的自带键盘保留。客户端已不再内置中文键盘。
7. 客户端升级：已内置 GitHub Releases + 服务端双源自动更新，**每次启动强制检查**，有更新必须更新成功才能进入；班管不需要手动发更新包。也可在停用时手动替换 `liaisonyy.exe`（保留同目录 `data\`，里面是本机设置/缓存）。
8. 如果发现多个服务端，先联系总管理员确认，不要让学生随意连接。

> 学生只需要使用快捷方式登录/聊天；服务器地址、文件位置、更新都由班管负责。

---

## 2. 登录与入口

1. 从班管创建的桌面快捷方式启动 `liaisonyy.exe`，托盘左键打开小窗。
2. 点自己的账号，用**密码**登录。
3. 底部进入「我」→「管理」，打开管理页。
4. 也可以在浏览器打开 `https://服务器IP:47820/admin`，用班级管理员账号登录网页后台；网页后台主要给总管理员用，班级管理员在客户端管理页操作更方便。

---

## 3. 管理页功能

### 3.1 查看本班统计

点「刷新统计」，可以看到：

- 本班账号数
- 在线人数
- 今日消息数
- 消息总数
- 待处理好友申请
- 数据库大小

统计是**本班范围**；看不到别班数据。

### 3.2 生成重置密钥（最常用）

学生忘记密码时：

1. 在「生成重置密钥」区域填：
   - **学生 UID**（学生可以在「我」页看到自己的 UID；也可以从账号列表看到）
   - **有效期（分钟）**：例如 10、60、1440（24 小时）、10080（7 天）
2. 点「生成」。
3. 屏幕会显示一个 **8 位纯数字密钥**，只显示这一次，请立刻抄下来。
4. **线下**告诉该学生密钥和有效期。
5. 学生在登录页「忘记密码」里输入 UID/YY 号 + 密钥 + 新密码（可选新 PIN），即可重置。
6. 密钥只能用一次；输错 5 次或过期作废。需要时重新生成。

> 0.3.0 的班级管理员可以为本班学生生成重置密钥；重置时加密数据的恢复由客户端自动完成。如果学生连 PIN 也忘了，仍可重置登录密码，但旧聊天记录可能需要总管理员协助恢复。

### 3.3 班级群

- 每个班自动有一个班级群，全班账号都在里面。
- 班级管理员可以正常发言；也可以在「管理 → 公告管理」发布**本班公告**（会进入全班同学的系统通知）。
- 新同学加入后看不到入群前的消息，这是加密设计决定的；如需让新同学了解旧通知，请重新发一遍。

### 3.4 名单

- 本班名单的**导入/编辑只有总管理员能做**；班级管理员只能查看（学生注册页会显示未注册名单）。
- 如果发现名单有误（错别字、重名、转班），请联系总管理员修改。

### 3.5 好友申请与班级群

- 班级管理员也是普通用户，可以加好友、私聊、在班级群发言。
- 「管理 → 聊天解密」只能查看**本班学生**参与的会话，每次查看都会写入审计日志；请只在处理举报/恢复数据时使用，尊重同学隐私。

## 4. 新增管理功能

### 4.1 举报与处理

- 「管理」页会列出与本班相关的举报（本班学生举报或本班学生被举报）。
- 可执行：忽略、隐藏消息、禁言（默认 60 分钟，可改）、封禁。
- 被处理人和举报人都会收到系统通知；处理结果写入审计。

### 4.2 禁言 / 封禁

- 「管理 → 手动处理用户」输入 UID 和分钟数，可禁言/解除禁言/封禁/解封。
- 只能处理本班**学生**，不能处理其他班或管理员。
- 封禁会立即吊销该账号全部会话，学生无法登录。

### 4.3 公告

- 「管理 → 公告管理」发布本班公告；可删除本班公告。
- 全校公告只有总管理员能发。

### 4.4 转班审批

- 「管理 → 转班审批」：本班作为转出班或转入班时都能看到申请。
- 转出班管理员先同意 → 状态「转出班已同意」；转入班管理员再同意 → 通过。
- 任一方都可拒绝；总管理员可一次批准两侧。
- 通过后系统自动移出/加入班群并轮换班群密钥。

### 4.5 聊天解密（内部工具）

- 输入本班学生 UID → 加载会话 → 点会话查看明文。
- 仅用于处理举报、协助恢复；所有密钥读取都会记入审计。
- 不要把解密内容转发或公开。

### 4.6 重置密钥

- 生成 8 位一次性密钥；有效期可选 10 分钟 / 1 小时 / 24 小时 / 7 天。
- 密钥只显示一次，线下交给学生本人。

## 5. 日常处理建议

### 学生忘记密码

1. 确认学生身份（当面/线下）。
2. 生成 8 位密钥，告诉学生。
3. 提醒学生：密钥只一次、有效期有限；重置后旧 PIN 可能被清除（如果学生没填新 PIN，账号会变成仅密码登录）。
4. 如果学生重置后看不到旧聊天，联系总管理员做密钥恢复。

### 学生 PIN 输错被锁

- 等锁定时间过去再试；或让学生用密码登录。
- 如果学生忘记 PIN 但记得密码：用密码登录后，在「我 → 密码与 PIN」里重设 PIN。
- 如果密码也忘了：走重置密钥流程。

### 学生说「加不了好友」

- 确认对方 UID/YY 号正确。
- 确认双方不是已经好友、没有待处理申请。
- 好友申请每小时最多 20 条，超出后等一会儿再试。

### 学生说「班级群看不到消息」

- 新成员看不到入群前消息，这是正常的。
- 如果显示「等待群密钥同步」，让该学生重新登录；仍不行则联系总管理员。

---

## 6. 安全与隐私

- 班级管理员账号请使用强密码；不要和学生共用。
- 重置密钥相当于临时登录凭证，只能线下交给本人，不要发在群里。
- 不要尝试查看学生私聊；当前版本也没有这个入口。
- 管理操作会写入审计日志（总管理员可查）。
- 服务器是教室电脑，可能关机/还原；重要通知请同时用线下方式传达。
